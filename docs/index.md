# translate-and-literate Documentation

Welcome to the documentation for **translate-and-literate**.

This project focuses on one idea:  
**translation quality emerges through iteration with a human editor.**

---

## Philosophy

Fluency is easy.  
Voice is hard.

Modern language models can generate grammatically correct text, but literary quality requires judgment, restraint, and intent. This system assumes that:

- AI proposes
- Humans decide
- Systems learn from decisions

---

## Architecture

- Agent-based workflow
- Code-agent execution (Codex / Claude Code)
- Repository-first design
- No UI coupling

---

## What this is not

- Not a black-box translator
- Not a fine-tuned model replacement
- Not a fully autonomous writing system

---

## What this is

- A structured editorial pipeline
- A style-learning system driven by diffs
- A scalable way to preserve authorial voice

---

## Getting started

1. Add a source text
2. Run the workflow
3. Edit the result
4. Let the system learn from your edits
5. Repeat

Over time, the output converges toward your editorial voice.
